# Локальная статистика и оригинальный оверлей

Кнопка «Статистика» в главном окне открывает отдельное обычное окно. Сверху на обеих вкладках видны общий счёт, текущий/прошлый матч, сессия и среднее. «Награды и шансы» открывает калькулятор, «История матчей» — таблицу, стартовую корректировку и HTML-отчёт. Кнопка «Оверлей» показывает его текущее состояние и включает или выключает его. Окно статистики можно свернуть; оно не закреплено поверх игры. В нём:

- общий счёт, включая стартовое значение и доступный текущий матч;
- сессия по существующим правилам программы: матчи, завершившиеся после запуска, с допуском 2 минуты;
- вся история выбранного профиля и среднее по завершённым матчам;
- стартовое количество сундуков до установки: измените число и нажмите «Применить». Оно не влияет на среднее и историю;
- выбор награды, редактируемый шанс 1/N, расчёт для следующих N сундуков;
- вероятность хотя бы одной награды, ожидаемое количество наград, среднее число попыток до первого дропа и пороги 50/90/99%;
- кнопка прежнего HTML-отчёта.

Оригинальный оверлей показывает общий и текущий/прошлый матч, сессию, среднее и сокровища; во время матча также может показывать предыдущий результат. Ctrl+Shift+O показывает или скрывает его, Ctrl+Shift+L закрепляет и пропускает клики. Для отображения поверх игры используйте оконный режим без рамки. Чтение реплея может быть недоступно до завершения матча: «…» означает ожидание данных, а не ноль сундуков.

## Шансы, предоставленные пользователем

Обычные матчи, один сундук. Эти значения перенесены со скриншота пользователя, не проверяются и не обновляются через интернет.

| Награда | Шанс | Повторяемость |
|---|---:|---|
| Weekly Gold Outfit | 1 / 1 562 500 | один раз |
| Pirate Shop Access | 1 / 137 500 | один раз |
| Weekly Vehicle and Decal | 1 / 7 813 | один раз |
| Weekly Pickaxe or Back Bling | 1 / 568 | один раз |
| Weekly Jam Track | 1 / 391 | один раз |
| Weekly Loading Screen | 1 / 272 | один раз |
| Any Gizmo | 1 / 127 | повторяемый |

«Уже получено» отмечается вручную и сохраняется отдельно для профиля. У одноразовой награды после отметки вероятность повторного получения равна нулю. Если появилась новая доступная награда, отметку нужно снять вручную: автоматического недельного сброса нет. Гизмы не помечаются как исчерпанные. Изменённые шансы сохраняются для каждой категории, кнопка «Исходный шанс» возвращает значение из таблицы.

Расчёт предполагает независимые попытки с постоянным шансом p = 1/N, без гарантии, и применимость выбранной награды к каждому учтённому сундуку. Для k сундуков P(хотя бы один) = 1 − (1 − p)^k. Математическое ожидание повторяемых наград равно kp, одноразовой — P(хотя бы один), не больше 1. Ожидаемое число попыток до первого успеха — N; это не гарантия получения за N сундуков. История сундуков сама по себе не доказывает получение награды.

## Данные и проверка

Все настройки и отметки сохраняются в существующем `%APPDATA%\ChestCounter\config.json`, матчи — в `data.json`. Новых сетевых обращений, телеметрии и автообновлений нет. Прежний локальный сервер OBS остаётся необязательным и выключенным по умолчанию. Чтение и разбор реплеев не изменены.

Сборка: `build.bat` (нужен .NET 10 SDK). Проверки без стороннего тестового пакета:

```powershell
dotnet run --project tests/ChestCounter.Checks -c Release -p:OfflineBuild=true -- <папка-результатов>
```

Проверяются вероятности и граничные значения, одноразовые награды и гизмы, изоляция профилей, стартовое число, сессия, история больше 100 матчей, сохранение настроек, переход live → завершённый матч и отрисовка окон. Проверки используют искусственные данные в указанной папке, а не пользовательскую историю.
